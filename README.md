# Turbo Poyga

Онлайн-гонки в браузере: до 8 игроков, комнаты для друзей и быстрая игра. Репозиторий называется `arcade-hub`: позже сюда могут добавиться другие игры.

## Стек

- **Сервер:** Node.js + TypeScript + Fastify + WebSocket (`@fastify/websocket`)
- **Клиент:** Vite + TypeScript + Three.js
- **Общее:** папка `shared` — типы сообщений и физика (одинаковая на клиенте и сервере)

Сервер авторитетный: считает физику 20 раз в секунду и рассылает состояние. Клиент отправляет только нажатия клавиш.

Клиент считает свою машину с тем же шагом (`shared/src/games/car/prediction.ts`). В состоянии сервер присылает `ack` — номер последнего обработанного ввода, а клиент заново просчитывает всё, что отправил после него.

## Правила гонки

- Машины едут только во время гонки
- После первого финиша у остальных 30 секунд, затем места раздаются по пройденной дистанции
- Гонка без финишировавших закрывается через 6 минут
- Зашедший посреди гонки стартует в следующей

## Трассы и машины

| Трасса | Круг | Кругов |
|---|---|---|
| Кольцо | 390 м | 3 |
| Долина | 1180 м | 2 |
| Серпантин | 1590 м | 2 |

Машины: седан, спорткар, хэтчбек, внедорожник. Цвет выбирается отдельно.

- **Новая машина:** характеристики в `shared/src/games/car/cars.ts` (запись в `CARS` и id в `CarId`), внешний вид в `client/src/render/carModels.ts` (`SHAPES`)
- **Новая трасса:** точки центральной линии в `shared/src/games/car/tracks.ts` (`DEFS` и id в `TrackId`), окружение в `client/src/render/world.ts`
- Тест `tests/tracks.test.ts` проверяет, что каждая машина проезжает каждую трассу и не выходит за ограждение

## Стили

«Аркада» (день) и «Неон» (ночь). Выбор влияет только на картинку и запоминается на устройстве, поэтому игроки с разными стилями могут ехать в одной гонке.


## Локальный запуск

```bash
npm install
npm run dev          # сервер :3000 + клиент :5173
```

Открой http://localhost:5173

## Проверки

```bash
npm run typecheck
npm test
npm run build
```

Те же проверки запускаются в GitHub Actions.

## Production (Render)

- **Build:** `npm install --include=dev && npm run build`
- **Start:** `npm start`
- Сервер отдаёт собранный клиент из `dist/client` и слушает WebSocket на `/ws`
- Health-check: `GET /health` (для cron-job.org, чтобы бесплатный инстанс не засыпал)

## Игры

- **Гонки (car)** — Turbo Poyga: серверная физика, комнаты по коду и быстрая игра
- **Hole.io** — отложен (папка `games/hole`)

Новая игра = новая папка в `server/src/games/` + `client/src/games/` + при необходимости `shared/src/games/`.

## Комнаты

- **Код комнаты** — для друзей (поле «Код комнаты»)
- **Быстрая игра** — подбор в открытую комнату с той же трассой или создание новой. Комнаты, созданные по коду, в подбор не попадают
- Трассу выбирает тот, кто создаёт комнату. Ссылка на комнату содержит и код, и трассу
